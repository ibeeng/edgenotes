Cerita Cara kerja Fitur Pasang

Catatan yang nempel di pinggir layar.

Sticky notes untuk Linux. Catatanmu jadi tab kecil di tepi layar: arahkan mouse untuk ngintip, klik untuk buka. Nggak ada jendela yang nutupin kerjaan.

Unduh .deb untuk Ubuntu Pasang di Arch / Omarchy

Gratis dan open source (GPLv3). Tanpa akun, tanpa cloud.

Kenapa aku bikin ini

Aku bikin aplikasi ini buat nulis catatan pas lagi ngerjain project. Catatannya harus selalu kelihatan, tapi nggak boleh ganggu.

Bikinnya dibantu AI. Idenya, alurnya, dan yang ngetes tiap hari tetap aku sendiri. Dan ternyata beneran kepake: project-ku kelar sampai selesai.

0/12 dicentang

Catatanmu nggak ke mana-mana.

Tanpa akun, tanpa cloud, dan nggak ada kode jaringan sama sekali. Semua tersimpan di ~/.local/share/edgenotes/notes.json, plus cadangan .bak otomatis.

Pasang

Unduh file .deb dari halaman rilis terbaru, lalu:

sudo apt install ./edgenotes_*_all.deb
edgenotes --install-shortcuts
edgenotes &

Tanpa sudo untuk pasangnya. ~/.local/bin sudah ada di PATH Omarchy.

sudo pacman -S --needed python-gobject python-cairo gtk3
git clone https://github.com/ibeeng/edgenotes && cd edgenotes
make install PREFIX=~/.local
edgenotes --install-shortcuts
edgenotes &

Butuh Python 3, PyGObject, pycairo, dan GTK 3 dari package manager distromu.

git clone https://github.com/ibeeng/edgenotes && cd edgenotes
sudo make install
edgenotes --install-shortcuts
edgenotes &
